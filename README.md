## HomeBank — personal finance, done properly

**[homebank.app](https://homebank.app)** · public beta on TestFlight

HomeBank is a personal finance app for iPhone, iPad and Mac: accounts, scheduled
payments, loans, budgets by envelopes and reports, with imports from most bank formats.
The free core is complete and unlimited; premium adds continuous iCloud sync, household
sharing and advanced reports. Your data always stays yours: export, backup and leaving
are free. Native SwiftUI on every platform, same features on iPad and Mac.

Join the beta from [homebank.app](https://homebank.app). Feedback and bug reports are
welcome: every fix ships with a test.

## outskirts — find unused code in Swift projects

**[outskirts.dev](https://outskirts.dev)** · `brew install tiny-earth-moon/tap/outskirts`

A community-maintained fork of Periphery 3.x, kept current with the latest Xcode and
Swift toolchains, with a bounded build cache and a single scan for SwiftPM and Xcode
projects. Issues and pull requests are welcome; every release is validated on real
codebases before it is tagged.

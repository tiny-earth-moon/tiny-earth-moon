# tiny earth moon

Indie developer building for iOS and macOS, in Swift.

## Projects

- **[HomeBank](https://homebank.app)** — personal finance for iPhone, iPad and Mac: accounts, budgets by envelopes, reports, imports from most bank formats. Extensive free core, optional iCloud & bank sync. Currently in public beta on TestFlight.
- **[outskirts](https://github.com/tiny-earth-moon/outskirts)** — find unused code at the outskirts of your Swift project. A community-maintained fork of Periphery 3.x, kept current with the latest Xcode and Swift toolchains, with a bounded build cache and one scan for SwiftPM and Xcode projects. `brew install tiny-earth-moon/tap/outskirts` · [outskirts.dev](https://outskirts.dev)

## Contributing to outskirts

Issues and pull requests are welcome. Every fix ships with a test, and every release is validated on real codebases before it is tagged. Start with the [roadmap](https://github.com/tiny-earth-moon/outskirts/issues/241).
